# Wave Image Generator

![Alt text](images_output\image.png "image")

A simple Python module to generate images of interfering waves.

## Key Features
- Generate images of wave interference patterns
- Easy to use Python module
- Customizable parameters for waves
- Use your own data files

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/username/Wave-Image-Generator.git
   ```
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
Run the `__main__.py` file from the source directory to start the program. Input a data file path and an output file path into the console to allow the program to load the data and store the image at the given location.

## Dependencies
- Pillow
- Numpy
